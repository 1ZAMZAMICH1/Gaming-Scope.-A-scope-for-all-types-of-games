## 🌟 Особенности
- **Ultra-Modern Cyberpunk UI**: Современный дизайн с эффектами размытия (glassmorphism), неоновыми акцентами и плавными анимациями.
- **Undetectable & Safe**: Отрисовка самого прицела написана на чистом `C# (Win32)`, она запускается как скрытый дочерний процесс. Прицел не внедряется в код игры (zero injection), что делает его на 100% безопасным от VAC, FaceIT и EAC (требуется режим "В окне без рамок").
- **Абсолютная точность**: Прицел математически держится в центре монитора и игнорирует баги масштабирования Windows (DPI Scaling).
- **Глобальные хоткеи**: Назначьте любую удобную кнопку (например, `Insert`), чтобы скрывать/показывать прицел прямо во время рейда на сервере.

## 🚀 Как использовать
1. **Скачать**: Перейдите в раздел **Releases** на Github (справа) и скачайте `ZGameCrosshairZ-1.0.0.exe`.
2. Запустите программу.
3. В удобном интерфейсе выберите цвет, форму прицела (Точка, Крестик, Кружок и т.д.), толщину линий и кнопку включения.
4. Вы можете нажать кнопку сворачивания (`—`), программа уйдет на панель задач и не будет отвлекать в игре!

## 🛠️ Технологии (Под капотом)
- **[Electron](https://www.electronjs.org/)** — для красивой панели настроек.
- **Vanilla JS & CSS3** — логика интерфейса.
- **C# WinForms** — неубиваемый движок отрисовки невидимого окна поверх всех игр.
